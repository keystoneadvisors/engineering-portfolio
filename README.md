# Engineering Projects

A collection of active hardware, software, and operations projects.

Each project page begins with a short summary and then documents the problem, architecture, important design decisions, current state, and remaining work. Projects are labeled clearly when they are still being designed, fabricated, or validated. Source code for these projects is currently private while the work is being actively developed. I’d be happy to provide access to any relevant repository. 

## Projects

### [Modular Greenhouse Control Node](projects/greenhouse-node.md)

An ESP32-S3-based environmental monitoring and control node with a custom PCB, parametric main enclosure, and removable rain-resistant sensor pod.

**Current state:** Mechanical and PCB design are in active iteration. Fabrication, firmware bring-up, and environmental testing are pending.

### [NAND Analyzer and SSD Development Fixture](projects/nand-analyzer.md)

A socketed NAND identification and test fixture, paired with a traceable workflow for matching raw NAND packages, controller boards, manufacturing tools, and validation results.

**Current state:** The V1 carrier PCB has been fabricated. Assembly and electrical bring-up are pending, and the stand requires a mounting-hole spacing revision.

### [Restaurant Operations Intelligence Platform](projects/mea-case-study.md)

A deployed system that converts fragmented restaurant inputs into scheduled operational reports, cost analysis, purchasing recommendations, and exception visibility.

**Current state:** Running for two independent restaurants. Production details and operating data remain private.
